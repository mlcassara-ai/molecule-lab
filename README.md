# Molecule Lab

Chemistry games for kids, built to go with a LINKTOR molecular model kit.

**Live site:** https://mlcassara-ai.github.io/molecule-lab/

## Games

| Game | What it teaches |
| --- | --- |
| Atom Jar | Drop atoms, bond them by real rules, chain molecules into wax, plastic, starch and wood |
| Atom Builder | Add protons, neutrons and electrons; see elements, isotopes, ions and radioactive decay |
| Electron Tug-of-War | Ionic bonding: sodium and chlorine make salt |
| Share-a-Pair Water | Covalent bonding: two hydrogens share with one oxygen |
| Sugar Factory | Building glucose, 24 atoms at a time |
| One Drop Zoom | Scale, from one water molecule out to a drop on a dime |
| DNA Zipper | Base pairing, the double helix and copying |

## Printables

In `print/`: a molecule builder booklet, a kid-sized periodic table, a how-atoms-build-everything page and a sugar build sheet.

## Notes

Every game is a single self-contained HTML file. No build step, no dependencies. Open one in a browser and it runs.
The version number shows in the corner of each game and at the bottom of the home page.
